# G3 Architects

A modern, one-page architecture landing page designed to showcase a professional design studio and its services. The project focuses on clean visual hierarchy, bold typography, and a polished layout for a premium architectural brand.

## Primary Technologies Used

- HTML5
- CSS3
- Google Fonts (`Work Sans`)
- Static image assets
- GitHub Pages for deployment

## Key Features

- Hero section with strong branding and call-to-action button
- Navigation bar with a clean landing-page layout
- Team showcase gallery
- Feature highlights and service sections
- Experience badge card for brand credibility
- Statistics/facts section for project metrics
- Sponsor showcase section
- Responsive layout for desktop and smaller screens

## Project Dependencies

This project is a static website, so it does not require a package manager or build tools.

- No npm dependencies
- No framework required
- Local image assets stored in the `images/` folder
- Fonts loaded via Google Fonts CDN

## How to Run Locally

### Option 1: Open directly in a browser

1. Download or clone the repository.
2. Open the `index.html` file in your browser.

### Option 2: Run a local web server

```bash
cd g3-architect-website
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```
